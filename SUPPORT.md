# Support

AI Edit Studio is open source (MIT). There is **no personal support** (no e-mail, chat or calls).

1. **Something doesn't work?** Run `node cli.mjs doctor` and follow [TROUBLESHOOTING.md](TROUBLESHOOTING.md) —
   it lists every error code with the fix. Using an agent? Ask it to use the `troubleshoot` skill.
2. **Still broken?** Open an issue on the project page with the error `code`, the `doctor` output and the last lines
   of `<data folder>/logs`. Never attach footage, project files or API keys. Issues are read in batches; there is no
   guaranteed answer or response time.
3. **Want to help?** Pull requests are welcome. Run `node --test` first.

Fixes arrive as new versions: unzip the new version and run its installer again; your projects stay where they are.
